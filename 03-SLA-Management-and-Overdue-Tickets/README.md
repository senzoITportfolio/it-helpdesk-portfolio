# 03 – SLA Management and Overdue Tickets

## 1. Lab Overview

This lab demonstrates how Service Level Agreements (SLAs) are configured and managed in osTicket. It focuses on defining ticket resolution targets, monitoring deadlines, managing overdue tickets, and ensuring that support requests are handled within agreed timeframes.

## 2. Objectives

- Understand the purpose of Service Level Agreements in IT Support.
- Create and configure SLA plans.
- Set ticket resolution timeframes.
- Configure business schedules.
- Monitor overdue support tickets.
- Apply SLA plans to support tickets.

## 3. Environment and Tools

- **Ticketing System:** osTicket
- **Environment:** Docker Desktop
- **Platform:** Windows 11
- **Database:** MariaDB
- **Lab Type:** Practical IT Support / Help Desk Simulation

## 4. SLA Plan Configuration

An SLA plan was created in osTicket with the following configuration:

- **SLA Name:** High Priority – 8 Hours
- **Grace Period:** 480 minutes
- **Schedule:** 24/5
- **Overdue Alerts:** Enabled

The configuration establishes an eight-hour target within the selected business schedule for handling assigned support tickets.

## 5. SLA Assignment and Management

The configured SLA plan was applied to a support ticket to demonstrate how service-level targets are assigned and monitored within the ticketing system.

The ticket details included the assigned SLA plan and its corresponding due date.

## 6. Overdue Ticket Monitoring

Overdue ticket monitoring helps support teams identify tickets that have exceeded their assigned SLA deadlines.

Monitoring overdue tickets supports timely follow-ups, escalation, and improved service delivery.

## 7. Key Skills Demonstrated

- SLA configuration and management.
- Ticket deadline monitoring.
- Service-level target management.
- Overdue ticket monitoring.
- IT Support workflow management.
- osTicket administration.
