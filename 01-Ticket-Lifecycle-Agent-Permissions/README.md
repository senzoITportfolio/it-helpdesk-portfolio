4. Key Concepts
Ticket Lifecycle

The ticket lifecycle represents the stages a customer support request passes through, from initial submission to resolution and closure.

Typical stages include:

Ticket creation
Ticket assignment
Investigation
Customer communication
Resolution
Ticket closure
Agent Permissions

Agent permissions determine what actions support staff can perform within the help desk system.

Examples include:

Viewing assigned tickets.
Responding to customer requests.
Updating ticket information.
Managing ticket status.
Accessing authorised support functions.
